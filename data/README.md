# Local data

This folder is private and git-ignored except for this README and `sample_sweetspot_ride.tcx`, a synthetic import example. A new clone starts with no rides.

Use **History > Import** for FIT, TCX, CSV and Apex JSON/gzip backups. Imports populate this browser's database; dropping files into this folder alone does not import them.

- `backups/`: compressed local backups; newest 14 retained.
- `health/`: Health Auto Export token, status and incoming payloads.
- `local-history.json`: optional private archive generated by `tools/parse_healthfit.ps1`. Older archive filenames are still recognised without rewriting them.

Optional Windows helper: set `HEALTHFIT_DIR` to your cycling FIT folder, then run `powershell -File tools\parse_healthfit.ps1 -RiderName "Rider"`. Normal file import is simpler and retains detailed samples. The server reads JSON directly; `tools/create_js_data.ps1` also supports a JavaScript wrapper.

Do not share your installed data directory. Share tracked source files. See [local setup](../docs/LOCAL-SETUP.md) and [privacy](../docs/PRIVACY.md).
